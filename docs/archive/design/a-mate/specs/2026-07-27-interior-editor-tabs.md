# 인테리어 편집 탭 정리

## 결정

- `인테리어 설정` 내부의 벽지·바닥 테마 선택 영역을 `디자인` 탭으로 분리한다.
- 탭 순서는 `디자인`을 첫 번째로 두고, 기존 가구 카테고리 탭들을 뒤에 둔다.
- 편집기 진입 시 `디자인` 탭을 기본으로 연다.
- 디자인 카탈로그는 가구 카탈로그와 같은 5열 카드로 표시하고, 한 페이지에 5개씩 페이지를 전환한다.
- 가구 카탈로그는 카테고리별로 한 페이지에 4개씩 표시하고 페이지를 전환한다.
- 가구 카테고리 탭을 열어도 첫 아이템을 자동 선택하지 않는다. 가구는 사용자가 카탈로그에서 명시적으로 선택한 뒤에만 배치할 수 있다.
- 배치된 가구의 우클릭 메뉴는 실제 크기를 측정해 방 뷰어 경계 안으로 보정한다. 닫기 버튼은 메뉴 내부 행을 차지하지 않고 우상단 테두리에 걸친 작은 연붉은 원으로 표시하며, 기존 바깥 클릭 닫기도 함께 제공한다.

서버 프로토콜, 방 디자인 저장 형식, 홈 및 설정 화면의 정보 구조는 변경하지 않는다.

## 진입 버튼

- 소유자 방의 보기 화면 좌측 상단에 원형 톱니바퀴 버튼을 오버레이한다.
- 기존 제목 행의 `인테리어 설정` 텍스트 버튼은 제거한다.
- 편집 중에는 진입 버튼을 숨기며, 아이콘 버튼에 접근성 이름과 툴팁을 제공한다.
