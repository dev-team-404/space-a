# 코칭 v2.1 PR① — 수집 기반 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 트랜스크립트 JSONL에서 tool_result 상태·첫 사용자 프롬프트·cwd·compaction 경계를 수집하고, 프로즈는 DB에 두지 않고 포인터로 지연로드(deref)할 수 있게 만든다 — 이후 R11/context_drift/R10 룰의 결정론 재료를 깐다.

**Architecture:** Claude Code 어댑터를 확장해 `user`/compaction 라인을 새 이벤트 종류(ToolResult·Compaction·UserPrompt)로 파싱한다. 세션 단위 필드(cwd·git_branch·first_prompt)는 `sessions` 테이블로 라우팅하고(events에 안 쌓음), tool_result 상태 enum과 deref 포인터(source_file+offset)를 events에 저장한다. 프로즈(프롬프트/에러 전문)는 원본 JSONL에 남겨 필요 시 `deref_jsonl_line`으로 읽는다.

**Tech Stack:** Rust 2021, rusqlite 0.32(bundled), serde_json, anyhow. 크레이트 `agent-mentor`(lib `agent_mentor`, `crates/core`).

## 스펙 대비 구현 정제 (플랜 단계 결정 — 검토 요망)

스펙 §4.3의 "SessionMeta·UserPrompt → sessions" 라우팅을 다음으로 구체화한다(관찰 계약 동일, 효율·최소 churn):

- **cwd/git_branch**: 어댑터가 라인마다 `EventKind::SessionMeta { cwd, git_branch }`를 방출 → `upsert_events`가 sessions에 COALESCE(최초값 유지)로 반영, events엔 안 쌓음. (`NormalizedEvent`에 필드 추가하지 않아 기존 생성자 churn 없음.)
- **first_prompt**: `EventKind::UserPrompt { preview }` → sessions.first_prompt_*에 COALESCE 반영, events엔 안 쌓음. 포인터(first_prompt_source_file/offset)는 그 라인의 **시작 byte offset**(off_bump=0)이라 deref가 정확히 그 라인을 읽는다.
- **tool_result deref 포인터는 이 PR 범위 밖**(YAGNI). ToolResult 행은 R11이 필요로 하는 `result_status`+`tool_use_id`만 저장하고, dedup 유일성을 위해 기존 off_bump 방식(줄 내 블록 인덱스)을 유지한다. 에러 전문 deref는 상세 UI가 필요한 후속 PR에서 포인터 표현을 확정.

```rust
use std::io::{BufRead, BufReader, Seek, SeekFrom};

/// 포인터(source_file + 라인 시작 byte offset)가 가리키는 JSONL 한 줄을 파싱해 반환.
/// 프로즈(프롬프트/에러 전문)를 DB에 두지 않고 필요 시 원본에서 지연로드하기 위한 것(스펙 §3).
/// 파일 부재·파싱 실패·빈 줄이면 None (미리보기 fallback은 호출부 책임).
pub fn deref_jsonl_line(source_file: &str, offset: u64) -> Option<serde_json::Value> {
    let f = std::fs::File::open(source_file).ok()?;
    let mut reader = BufReader::new(f);
    reader.seek(SeekFrom::Start(offset)).ok()?;
    let mut line = String::new();
    let n = reader.read_line(&mut line).ok()?;
    if n == 0 {
        return None;
    }
    serde_json::from_str(line.trim_end_matches(['\n', '\r'])).ok()
}
```
