# 문서 아카이브

이 디렉터리는 프로젝트 진행 중 작성된 설계안과 작업 이력을 원래 구조에 가깝게 보존합니다. **현재 제품 범위나 구현의 기준 문서가 아닙니다.**

| 위치 | 내용 |
|---|---|
| [`highlevel/`](./highlevel/) | 제출 문서 정리 이전의 하이레벨 개요·데모·데이터 흐름 |
| [`design/`](./design/) | 컴포넌트별 설계안, 스펙, 플랜과 완료된 작업 기록 |

현재 상태는 [프로젝트 README](../../README.md), [PRD](../PRD.md), [통합 아키텍처](../architecture/README.md)를 기준으로 확인합니다. 아카이브 문서는 당시 맥락을 조사할 때만 사용하며, 내부 링크나 용어가 현재 구조와 다를 수 있습니다.
