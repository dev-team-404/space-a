# AI 사용 코칭 (Level 1)

> [← 개요](./level-0.md) · 핵심 기능 #1

사용자 PC에 설치된 Agent가 **개인 Claude 로그를 분석**해, 적은 토큰으로 최고의 성과를 내도록 실시간 코칭한다.

## 무엇을 코칭하나

현재 등록된 결정론 규칙은 3종이고, 그 위에 LLM 판정 계층이 얹혀 있다.

| 규칙 | 내용 |
|---|---|
| **R6** | 같은 지시가 반복됨 → 실사용 도구를 집계해 **SKILL.md 초안**까지 만들어 준다 |
| **R7** | 사소한 작업에 상위 모델 → 다음 세션의 모델 선택 권고 |
| **R8** | MCP가 매번 대형 결과를 반환 → "필드 좁히기" 권고. **유일한 팀 공유 대상** |

여기에 세 가지가 더해진다.

- **오늘의 배움** — 공식 CHANGELOG·창시자 팁·플러그인 카탈로그·**팀 지식**을 역량 프로필에 맞춰 랭킹
- **1인칭 일기** — 하루 사용 기록을 마스코트 시점으로 서사화
- **인정 알림** — 내가 올린 지식을 팀원이 쓰면 마스코트가 축하한다

## 예시

```
"이 작업은 고성능 모델이 아니어도 충분합니다."
"비슷한 요청이 반복되고 있습니다. Skill로 만들어두면 좋습니다. (초안 만들어뒀어요)"
"이 MCP가 최근 20번 호출에서 평균 8k자를 반환했어요. 필드를 좁혀보세요."
"주인님이 올린 지식을 다른 팀에서 가져다 썼어요!"
```

## "뻔한 조언" 문제를 어떻게 풀었나

킥오프의 핵심 과제였다. 지금 수준의 코칭("MCP 쓰지 마세요")은 누구나 아는 내용에 그치기 쉽다.
세 갈래로 대응했다.

1. **규칙을 줄였다** — 12종 → 3종. 뻔하거나 오탐인 규칙을 은퇴시키고, 남긴 것에
   **LLM 판정**을 얹어 "이게 진짜 지적할 만한가"를 한 번 더 거른다.
2. **내 로그의 숫자로 말한다** — "평균 8k자를 20번"처럼 측정값을 인용한다. 일반론이 아니다.
3. **밖에서 배울 것을 붙였다** — 규칙이 못 잡는 부분은 큐레이션 피드와 팀 지식이 채운다.
