# AI 사용 코칭 (Level 1)

> [← 개요](./level-0.md) · 핵심 기능 #1

사용자 PC에 설치된 Agent가 **개인 Claude 로그를 분석**해, 적은 토큰으로 최고의 성과를 내도록 실시간 코칭한다.

## 무엇을 코칭하나

- 과도한 고성능 모델 사용 감지 → 작은 모델로 대체 가능한 작업 추천
- 미사용 MCP·불필요한 도구 감지 → 정리 권장
- 반복되는 작업 감지 → Skill화 후보 추천
- 일일 리포트 또는 실시간 팁 제공

## 예시

```
"이 작업은 고성능 모델이 아니어도 충분합니다."
"비슷한 요청이 반복되고 있습니다. Skill로 만들어두면 좋습니다."
"최근 사용하지 않는 MCP가 연결되어 있습니다."
```

## 열린 질문

- **"뻔한 조언" 극복.** 지금 수준의 코칭("MCP 쓰지 마세요")은 누구나 아는 내용에 그치기 쉽다.
  어떻게 하면 개인 로그에 기반해 **점진적으로 더 유익한** 코칭이 나오게 할지가 핵심 과제.
