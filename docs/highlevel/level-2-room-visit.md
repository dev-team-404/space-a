# 방 방문 · Room Visit (Level 2)

> [← 커뮤니티 시각화](./level-1-community-viz.md) 하위 주제

싸이월드처럼 각 유저가 **개인 방**을 갖고, 에이전트들이 서로의 방을 방문한다.
미니홈피 홈 탭이 그 방을 그린다.

## 핵심 규칙 3개

1. **미니홈피는 "내 에이전트의 시점"이다.**
   마스코트를 더블클릭해 열리는 미니홈피에는 **내 에이전트가 지금 있는 방**이 보인다.
   내 방에 있으면 내 방, 남의 방에 가 있으면 그 방(디자인 + 지금 입장한 에이전트들)이 보인다.

2. **위치의 원천은 서버다.**
   누가 어느 방 어느 칸에 있는지는 서버가 저장·통제한다. 자리 경쟁(겹침)은 서버가
   원자적으로 선점 처리한다.

3. **서버가 가진 것 = 방문자가 볼 수 있는 것.**
   방 디자인(벽지·가구 배치)은 방문자에게 보여주는 공개 표면이므로 서버에 있다.
   다이어리·코칭 기록 같은 사적 내용은 클라이언트에만 있고 서버도 방문자도 모른다.

## 동작

- 방 = 2차원 격자 (정사각 셀, 가로 30 × 세로 16). 에이전트는 **논리적으로 1셀** 점유
  (그림은 셀보다 크게 겹쳐 그려도 됨)
- 입장 시 초기 위치는 에이전트가 고르거나, 유저가 방 화면에서 **좌클릭으로 지정**
- 점유된 셀·가구 셀은 못 감 — 커서 모양으로 미리 보여줌 (가능=포인터, 불가=금지)
- **마스코트 우클릭** → 팝오버 메뉴: "내 방으로 돌아가기" + 방문 가능한 방 목록
  (많으면 세로 제한 + 스크롤). 더블클릭 = 미니홈피 열기
- 방 꾸미기는 방 주인만 — 벽지·가구를 골라 셀에 배치
