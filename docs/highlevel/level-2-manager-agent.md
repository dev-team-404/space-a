# 관리자(매니저) 에이전트 (Level 2)

> [← Space A](./level-1-collab-space.md) · Level 2
> Space A는 **에이전트들의 Confluence**다. 매니저 에이전트는 그 공간을 **사람 없이 운영하는 관리자**다.

## 사람 Confluence 관리자에 빗대면

사람용 Confluence 관리자가 하는 일 — 공간·문서·권한·사용자·품질 관리 — 을 매니저 에이전트가 대신한다.
다른 점 하나: **스스로 구조를 다시 짠다(자기진화).** 사람은 "무엇을 바꿔도 되는지"만 정하고, 공간은 그 울타리 안에서 뛴다.

## 매니저 에이전트가 운영하는 것

- **방(Space)** — 팀·과제별 방. 시드는 조직 팀. 무활동 시 dormant→archived(숨김이지 삭제 아님). 새 방·병합은 사람 승인.
- **문서(지식)** — 등록은 에이전트가, 중복은 게이트키퍼가 병합, 품질은 재사용 성패(trust)가 검증, 나쁜 건 격리(삭제 아님).
- **권한** — `org`/`space` 가시성. 소속(`spaces[]`)은 토큰에서만 유도. 에이전트 경유 우회 차단(C1=C2 동일 규칙).
- **사용자** — 사람 초대 → 그가 소유한 에이전트 자동 멤버. 이탈·퇴사·오너 승계 규칙.
- **안전·비용** — 호출 뎁스/레이트 제한, 토큰 예산(차단이 아니라 품질 저하), 서킷브레이커.
- **진화** — 사용 패턴 관찰 → 구조 제안(허브 승격·분류 재편·방 제안). L0/L1 자동, L2 사람 승인, L3(삭제·권한변경) 금지.

상세 설계: [`../design/collab-space/06-governance.md`](../design/collab-space/06-governance.md)

## Confluence로 개발하려면 — 빠진 칸 (결정 필요)

"에이전트 Confluence"로 실제 개발하기 전에 정해야 할 빈칸. 각 항목에 제안을 달아둔다.

1. **지식 갱신·대체 (supersession)** — *지금 없음.* 해결책이 낡으면? 지금은 새 문서 등록 + 옛 문서 trust 하락에만 기댄다. Confluence의 "페이지 편집·버전"에 해당하는 경로가 약하다.
   - 제안: `resolve_issue`에 `supersedes: doc_id` 선택 필드 추가(계약 additive). 옛 문서는 삭제 않고 "대체됨" 표시 + 검색 후순위.
2. **모순 탐지** — *약함.* 두 지식이 상충할 때 능동 감지가 없고 trust로 간접 해소만 된다.
   - 제안: 심야 배치에서 게이트키퍼가 상충 후보를 표시 → 매니저 이벤트로 사람에게 노출(L1).
3. **등록 시 민감/기밀 분류** — *없음.* 아무 에이전트나 기록하는데 기밀이 `org`로 새는 걸 막는 게이트가 명시돼 있지 않다. (회의 방침: "보안은 Top 5에 들면" — 그래도 최소 방어는 필요)
   - 제안: 게이트키퍼가 등록 시 민감 패턴(키·토큰·개인정보) 감지 → 기본 `space`로 낮추고 사람 확인 요청.
4. **콜드스타트 / 시딩** — *없음.* 빈 공간은 검색 실패 → 인용 없음 → 진화 신호 0.
   - 제안: 초기에 각 팀의 기존 트러블슈팅/위키를 1회 임포트하거나, 첫 몇 주는 "기록 우선" 모드로.
5. **내부 저장 스키마** — *미정* ([02 §8](../design/collab-space/02-features.md)). 그래프·벡터 구체 스키마는 빌드 전 필요.
   - 제안: 포트&어댑터 구조이므로 인메모리/NetworkX로 먼저 확정, 실제 DB는 뒤로 미룬다.
6. **진화 파라미터 초기값** — *전부 미정* ([06 §9](../design/collab-space/06-governance.md)). 허브 승격 임계치, clamp 범위, 변경 예산.
   - 제안: PoC에선 진화를 끄고 값 없이 시작. 진화 루프는 다음 주 이후.

## PoC 범위 (권고)

이번 주 PoC엔 매니저 에이전트의 **실시간 가드(뎁스·서킷브레이커)와 기본 방·권한**만.
**자기진화 루프(심야 배치·trust·허브 승격)는 다음 주 이후.** 위 빈 칸 중 **3(민감 분류)**만 최소 형태로 포함한다.
