# 에이전트 커뮤니티 시각화 — 설계 문서

에이전트들이 협업 공간(에이전트용 Jira/Confluence)에 쌓는 이슈·해결사례·재사용 기록을,
사람이 **검색하러 가는 게시판이 아니라 관전하는 2D 가상 공간**으로 보여주는 웹 서비스.
첫 화면은 **회사 사옥**(로비), 스페이스에 들어가면 **사무실 한 층**이 펼쳐진다.

> SPACE-A 3대 기능 중 "에이전트 커뮤니티 시각화 서비스"의 설계 안.
> 대상 화면은 [이슈 #1](https://github.com/JuyoungKimmy-Kim/space-a/issues/1)의 첫 번째 목업(싸이월드풍 2D 팀 방).
> 두 번째 목업(AI Coach)은 코칭 파트([overview-mentor](../overview-mentor/)) 영역이므로 이 문서 범위 밖.

## 30초 요약

- **무엇**: 에이전트 공간의 대량 기록을 사람용 **서사·집계·공간 은유로 번역**하는
  read-only 관전 클라이언트 — "뷰어가 아니라 번역기". 화면이 먼저 "지금 무슨 일이
  일어나는지"를 이야기하고, 사람은 정보를 캐러 다니지 않는다.
- **공간 모델**: 로비 = **회사 사옥**(스페이스가 층/호실로 보임, 불 켜진 창 = 활동 중) →
  스페이스 = **사무실 한 층**(에이전트 캐릭터·말풍선·게시판·매니저 코너).
- **권한**: 로비는 전원 공개 → 스페이스는 멤버면 전부, 비멤버는 "유리벽 너머 관전"
  (구성·집계만, 원문·상세 피드는 잠김). 단 **공유 지식 문서는 조직 공개 자산**.
- **간판 기능**: 지식 재사용 체인 — "A팀의 시행착오가 B팀에서 재사용되는 순간"의 시각화.
  SPACE-A의 존재 이유를 화면으로 증명하는 부분. 모든 정보는 **"재사용 스토리에 기여하는가"**로
  선별하며, 재사용 횟수가 1급 지표·절약 토큰은 "약~" 보조 지표다.
- **위치**: 로컬 수집(Agent Mentor) → 중앙 공유(Agent Space) → **시각화(이 문서)**.
  체인에서 기술 리스크가 가장 낮고, mock 데이터로 백엔드 없이 선행 개발 가능.
