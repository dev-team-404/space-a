# Agent Mentor — 기능 카탈로그

> 구현된 기능과 그 동작 방식의 전체 목록. 각 기능의 상세 설계는 [`specs/`](specs/)의 해당 스펙 참고.

## 1. 데이터 수집 (Windows + WSL 통합)

**무엇을**: Claude Code가 남기는 로컬 기록 전부.

- `~/.claude/projects/**/*.jsonl` — 세션 트랜스크립트 (메시지, tool_use/result, 토큰 usage, 모델명)
- `settings.json` / `~/.claude.json` / 프로젝트 `.mcp.json` — 활성 MCP 서버·플러그인 셋
- `skills/`·`plugins/` 디렉터리 — 설치 자산 스냅샷 (신규 감지 diff용)

**어디서**: Windows `%USERPROFILE%\.claude` + WSL 전 distro (`wsl -l -q`로 열거 →
`\\wsl.localhost\<distro>\home\*\.claude` UNC 접근, username 하드코딩 없이 자동 발견).
각 소스는 `host` 라벨(`Windows` | `wsl:<distro>`)로 구분되어 한 스토어에 통합된다.

**어떻게**:

- `notify` 파일 감시 → **60초 디바운스 배치**로 ingest → inventory → rules 재실행. WSL UNC는 30초 폴링 폴백.
- **증분 수집**: 파일별 offset 워터마크(`ingest_state`)부터 tail. 쓰이는 중인 미완결 라인은 버퍼링하고 완결 라인만 파싱 — 동시 다중 세션 append에 안전.
- **멱등 upsert**: `(session_id, seq)` 기준이라 재실행/재시작 안전.
- **관대한 파싱**: 스키마 이상은 로깅만, 절대 하드 실패하지 않음. 파일 단위 실패는 스킵.
- 앱 시작 시 풀 스캔 1회 + 놓친 변경 복구(워터마크 vs mtime).

**프라이버시 설계**: 대화 원문(프로즈)은 DB에 저장하지 않는다. 분류 플래그·미리보기 한 줄·
**원본 포인터(source_file + offset)** 만 저장하고, 세션 상세를 열 때만 JSONL에서 지연 로드(deref)한다.
원본이 삭제되면 미리보기로 graceful fallback.

## 2. 인벤토리 — always-on 비용의 지반

세션과 별개로 "지금 설정에 뭐가 깔려 있나"의 시점 스냅샷을 관리한다.

- 세 곳(글로벌 settings의 enabledPlugins / `~/.claude.json`의 프로젝트별 mcpServers / 프로젝트 `.mcp.json`)을 종합해 **세션에서 활성인 MCP 셋**을 산출.
- **snapshot-replace reconciliation**: 스캔마다 호스트별 인벤토리를 현재 활성 셋으로 원자적 교체(트랜잭션) — 설정에서 제거된 서버의 stale 행이 R1을 오탐시키지 않게. 단, 설정 파일 읽기가 일시 실패하면 그 호스트는 스킵(오삭제 방지 가드).
- 사용 이력(`events`)은 역사적 사실이라 절대 삭제하지 않음.
- **총 always-on 토큰 = 정확 측정**: 세션 첫 턴의 `cache_creation_input_tokens` ≈ 시스템 프롬프트 + 전체 도구 정의 + CLAUDE.md. 서버별 귀속은 차등+휴리스틱 추정("약 ~" 라벨).

## 3. 코칭 규칙 엔진 (Tier 0 — 결정론적)

모든 코칭은 **Finding** 1건으로 환원된다: `rule_id`, `severity(info|suggest|warn)`, `scope`,
`evidence`(원시 근거), **`est_tokens_saved`**(정량 임팩트), `prescription`(처방), `status`, `occurrences`.

### 나깅 방지

- dedup_key(`{rule_id}|{host}|{project_id}`) 기준 upsert — 같은 지적은 카드 1장에 occurrences만 증가.
- 상태머신 `new → shown → {snoozed | dismissed | following}`. **해결함/무시는 재스캔에도 유지**(자동 부활 없음), 복원은 "숨긴 항목" 토글에서 수동.
- `following` 전이(조언을 따르기 시작) 감지 → 규칙이 침묵하고 다이어리의 **칭찬거리**로 전환.

## 4. 다이어리 (flagship)

에이전트(마스코트)가 1인칭으로 쓰는 하루 일기. 단순 템플릿이 아니라 **LLM 필수**, 품질 > 정시성.

- **생성 트리거**: 자정 이후 첫 파이프라인 완료 시 전날치 자동 생성. PC가 꺼져 있었으면 다음 부팅 때 밀린 날짜를 순차 보충(backfill). 엔진 미인증 시 큐에 보류 후 엔진이 살아나면 생성(템플릿 폴백 금지).
- **파이프라인**: 그날 Findings(문제 + 칭찬거리 사실) 수집 → 브리프(JSON) 조립 → LLM이 페르소나·톤으로 서술 → 사용자 지정 디렉터리(예: Obsidian vault)에 날짜별 `.md` + SQLite 색인.
- **정밀도의 선**: LLM은 브리프의 사실·수치만 인용 가능. 근거(`detail`)·개선방향(`suggested_action`)은 규칙에서 결정론적으로 파생.
- **Occasions**: 명절(음력 설날·추석은 2025–2035 번들 정적 테이블, 로케일 인지)·기념일("주인과 처음 만난 날" = DB의 첫 세션 날짜 기준 50일/100일 단위/N주년)을 결정론적으로 계산해 서사에 반영.
- **칭찬거리 사실 공급**: 새 스킬/플러그인 설치 감지("주인이 새 무기를 구해왔다!"), 조언 채택(`following` 전이), 긴 세션인데 캐시율 높음 등 — 규칙은 사실만 공급하고 LLM이 맥락으로 인정.
- **톤 설정**: A(감성)/B(균형, 기본)/C(분석) + 호칭(기본 "주인") 사용자 지정.
- **문체 자연화**: 한국어 "AI티"(번역투·이중피동·상투구·이모지 남발)를 시스템 프롬프트의 문체 가이드(`voice_guidance()`)로 생성 시점에 예방.
- **자기 토큰 계량**: 일기 푸터에 "이 일기 ~N 토큰" 표기.

## 5. 마스코트 (데스크톱 캐릭터)

### 창과 렌더

- 투명·무테두리·alwaysOnTop의 작은 창(160×160, 말풍선 시 320×230로 일시 확장). 드래그로만 이동, 위치 영속화. 화면을 덮지 않는 "작은 창" 전략이라 클릭스루 폴링이 필요 없다.
- **절차 생성 로봇**: `SHA-256(호스트명+사용자명)` 시드 → Rust가 `RobotSpec`(antenna/head/eyes/body/arms 슬롯 × 변형 6종 + 팔레트 8종) 결정 — 사용자마다 다른 로봇. 렌더는 128px canvas **프로시저럴 드로잉**(셀 셰이딩 + 2px 아웃라인 + 볼터치 — 싸이월드 미니미풍 매끈한 스프라이트).
- **애니메이션 상태 머신**: `idle`(바운스·깜빡임) / `talk` / `happy`(점프+^^) / `alert`(안테나 점멸) / `sleep`(새벽 1–7시, zZ). `requestAnimationFrame` 단일 루프 + 순수 함수 `frameAt` (테스트 가능).

### 말풍선 (트리거 4종)

| 트리거 | 내용 | 클릭 시 |
|---|---|---|
| `coach:finding` | 새/악화 finding 알림 | chat 코칭 탭 |
| `diary:ready` | 일기 완성 | chat 다이어리 탭 |
| `occasion:today` | 기념일·명절 | chat 홈 탭 |
| 유휴 잡담 | 주기적 한마디 (아래) | chat 홈 탭 |

여기에 **실시간 조언**(옵트인, `realtime_advice` 설정): 스캔 완료 시 최상위 조언 1건을 말풍선으로 표시.
FIFO 큐(최대 5건), 의미 있는 것만·지속 표시·X 닫기. 에러는 절대 말풍선으로 알리지 않는다(홈 탭 상태줄·트레이 툴팁만).

### 마스코트 보이스 (LLM 페르소나 3부작)

다이어리·채팅과 **동일 인물**이 말하는 것처럼 들리게 하는 계열 기능. 모두 "정밀도의 선"과
`voice_guidance()` 문체 가이드를 공유한다.

1. **다이어리 문체 자연화** (PR #15) — 위 §4.
2. **오늘의 한마디** (PR #17) — chat 창 프로필 초상 밑 상시 1줄. 오늘 요약(`ChatContext`) 사실 기반, 스캔 완료 시 fingerprint(세션수|입력|출력|findings수)가 바뀐 경우에만 LLM 재생성 + 날짜 캐시. 활동 0건이면 LLM 없이 정적 1줄("오늘은 널널하네. 근데 좀 심심;;;").
3. **잡담 풀** (PR #18) — 잡담 말풍선을 정적 10개 → **LLM 1결 + 정적 2결** 혼합으로 업그레이드. 스캔 편승으로 하루 최대 1회 LLM 호출해 사용기록 연계 잡담 ≤5개를 배치 생성·캐시(`chatter_pool`), 프론트 타이머는 pick만(최근 표시 3개 회피). 엔진 미설정 시 정적만으로 자연 폴백. 빈도는 트레이 서브메뉴(자주 20–40분 / 가끔 60–120분(기본) / 안 함), 새벽 1–7시 침묵.

## 6. chat 창 = 미니홈피

싸이월드 미니홈피의 레이아웃 문법(타이틀바 방문자 카운터, 좌측 컬럼, 책갈피 탭)에
**파스텔 모던 스킨**(연보라·민트·크림·코랄, 둥근 모서리)을 입힌 메인 창. X 버튼은 destroy가 아닌 hide(상주 유지).

- **타이틀바**: "{사용자명}님의 미니홈피" + TODAY(오늘 세션)/TOTAL(누적 세션) 카운터.
- **좌측 컬럼**: 로봇 초상 + "오늘의 기분" + 오늘의 한마디(§5).
- **홈 탭**: 오늘 스트립(세션·입력·출력·절약가능) + 위젯 2×2(주간 추이 미니 바 차트 / 모델 분포 스택 바 / 절약 실천 top3 / 최근 알림) + **마이라이프**(파스텔 방 + 128px 로봇, 클릭 시 happy 모션+대사) + 상태줄(마지막 스캔·지금 스캔 버튼).
- **코칭 탭**: "무엇이(사람말 제목) → 왜(detail+관측 횟수) → 어떻게(suggested_action)" 카드. **명령 복사 버튼**(`claude mcp remove …` 등, 결정론 매핑), 해결함/무시 상태 관리, evidence JSON은 접힌 "원본 데이터 보기"로 격하. 절약 토큰 큰 순 정렬.
- **다이어리 탭**: 미니 달력(일기 있는 날 도트) → 날짜 선택 시 본문(경량 마크다운 렌더, sanitize).
- **채팅 탭**: 마스코트 페르소나와 1:1 대화. 기존 `Engine` 추상화 재사용 + **코칭 컨텍스트 주입**(오늘 요약·상위 findings). 트랜스크립트 원문은 전송하지 않는다. 범위 밖 요청("코드 짜줘")은 인격으로 정중히 넘김.

## 7. 트레이 & 상주

- Tauri v2 코어 tray API. 좌클릭 → chat 창 토글.
- 우클릭 메뉴: 열기 / 마스코트 표시 ✓ / 실시간 조언 ✓ / 화면 캡처 보호 ✓ / 잡담 빈도(자주·가끔·안 함) / 지금 스캔 / 설정 / 업데이트 확인 / 시작 시 실행 ✓ / 종료.
- **autostart**: `tauri-plugin-autostart`(공식 v2)로 부팅 시 자동 실행, 트레이에서 토글.
- **updater**: `tauri-plugin-updater`(공식 v2)로 인앱 자동 업데이트. 시작 시 체크 + 트레이 수동 체크 → chat 창 상단 배너. 피드는 공개 릴리스 저장소(`a-mate-releases`)의 `latest.json`. [ADR 0018](../../adr/0018-a-mate-auto-update-channel.md).
- 백그라운드 파이프라인은 전용 스레드 + 채널, watcher 사망 시 자동 재시작.

## 8. LLM 엔진 (Tier 1)

- `Engine` 추상화 뒤에 **사내 on-prem(OpenAI 호환 엔드포인트) 기본, Claude 옵션**. 기본 상태에서 데이터가 사내망을 벗어나지 않는다 — egress 프라이버시가 엔진 선택으로 해결되는 구조.
- 소비처: 다이어리 서사, 오늘의 한마디, 잡담 풀, 채팅 탭. 전부 **결정론적으로 증류한 컴팩트 브리프**만 전달(원문 트랜스크립트 통째 전송 금지).
- 스캔당 LLM 호출은 fingerprint 게이트로 최대 2회(한마디 1 + 잡담 풀 1)로 억제. 엔진 실패는 조용히 다음 사이클에 재시도.
