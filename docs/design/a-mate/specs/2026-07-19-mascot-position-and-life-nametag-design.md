# 마스코트 위치 복구와 라이프 네임태그 가독성 설계

## 배경

- 마스코트 위치는 개인 앱 데이터의 `mascot_pos=x,y`에 저장되므로 Git으로 공유되지는 않는다.
- 모니터 제거, 해상도·배율 변경 뒤에는 과거 절대 좌표가 화면 밖을 가리킬 수 있다.
- 기존 트레이 표시 토글은 창을 숨기고 보여주기만 하며 위치를 복구하지 않는다.
- 라이프 사용자 네임태그는 밝은 배경(`#fffaf0`)에서 전역 밝은 글자색(`--ink`)을 상속해 대비가 부족하다.

## 결정

### 마스코트 위치

1. 저장 좌표와 함께 현재 모니터의 물리 좌표·크기·DPI 배율로 만든 `mascot_display_layout` 지문을 저장한다.
2. 시작 시 지문이 없거나 현재 구성과 다르면 저장 좌표를 폐기하고 주 모니터 우하단으로 복구한다.
3. 지문이 같더라도 로봇 상호작용 영역이 화면 안에 없으면 복구한다.
4. 복구한 좌표와 현재 지문은 즉시 DB에 저장한다.
5. 트레이에서 마스코트를 다시 표시할 때도 같은 검증을 수행한다.
6. 트레이에 `마스코트 위치 초기화`를 제공한다.
7. 위치 지정과 창 표시 실패는 로그에 남긴다.

모니터 구성이 실행 중 바뀐 뒤 사용자가 이동한 경우에도 다음 시작에서 기존 지문과 달라져 안전한 위치로 복구된다.

### 라이프 네임태그

- 밝은 태그 표면에는 전역 다크 테마 글자색을 상속하지 않고 `#2b2520`을 명시한다.
- `font-weight: 600`, 옅은 테두리와 그림자로 다양한 라이프 배경에서 윤곽을 유지한다.

## 검증

- 동일 모니터 구성의 유효 좌표는 유지한다.
- 모니터 구성 또는 DPI가 바뀌면 저장 좌표를 사용하지 않는다.
- 보조 모니터 제거 후 화면 밖 좌표를 거부한다.
- 위치 초기화 메뉴로 주 모니터 안쪽에 복구할 수 있다.
- 라이프 네임태그 CSS가 밝은 배경과 어두운 글자 조합을 사용한다.
