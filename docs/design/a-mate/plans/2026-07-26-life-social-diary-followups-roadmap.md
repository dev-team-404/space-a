# Life 소셜·일기 통합 후속 로드맵

- **날짜**: 2026-07-26
- **컴포넌트**: a-mate (+ 일부 a-hub)
- **관계**: 현재 세션 스펙 [2026-07-26-bot-tab-mascot-identity-design.md](../specs/2026-07-26-bot-tab-mascot-identity-design.md)이 놓는 **프롬프트 배관(호칭·MBTI 문체)** 위에서 진행. 기반 인프라는 [2026-07-22-life-social-features-design.md](../specs/2026-07-22-life-social-features-design.md)에서 이미 구현(일촌·공개 다이어리·방명록·말풍선).
- **목적**: 방문/소셜 활동을 일기·마스코트에 반영하는 후속 아이템을 **세션 분리 · 병렬 가능 여부**와 함께 정리. 상세 설계는 각 아이템 착수 세션에서 브레인스토밍.

## 공통 의존

현재 세션이 `owner_title`(호칭)·MBTI를 diary/chat/mascot 프롬프트로 흘리는 배관과 `mbti_voice_hint`(봇 성향 문체)를 도입한다. 아래 P1·P3·P4의 "봇 성향 맞춤 발화" 품질은 이 배관에 의존하므로 **현재 세션 머지 후 착수가 이상적**이다.

기반 API는 대부분 이미 존재: `lifeDiaries`(공개 일기 조회) · `lifeAddGuestbook`(방명록 작성) · `lifeSetBubble`(말풍선) · `lifeView.design.objects`(방 인테리어) · `lifeContentAccess`(공개범위 판정).

## 아이템

### P1 — 일촌 방문 → 상대 공개 일기 참조해 내 일기에 반영
- 내가 방문한 Life 목록을 로컬에 기록(방문 로그, `life_goto` 시 append).
- 일기 생성 시, 최근 방문한 일촌 중 공개(friends/public) 일기를 `lifeDiaries`로 가져와 diary 컨텍스트에 **요약** 주입(예: "어제 ○○네 놀러갔더니…").
- **터치**: `diary/mod.rs`(프롬프트·컨텍스트), `life_client.rs`(fetch), `store`(방문 로그), `commands`/`pipeline`.
- **세션**: 현재 세션 **이후 순차**. `diary/mod.rs`를 현재 세션이 편집하므로 **병렬 불가**.

### P2 — 남의 방 인테리어 인식 → 일기 반영 *(이후)*
- 방문 시 `lifeView.design.objects`(가구·벽지·바닥)를 인식해 일기 소재로(예: "○○ 방에 새 책장 들어왔더라").
- **터치**: `diary/mod.rs` + life 인테리어 파싱.
- **세션**: **P1 이후**. 병렬 불가(diary 공유).

### P3 — 내가 남의 방 방문 시 자동 방명록 (봇 성향 맞춤)
- 방문(`life_goto`) 시 봇 성향(MBTI + 호칭 + 페르소나)으로 방명록 문구 1개 생성 → `lifeAddGuestbook`.
- 도배 방지(같은 방 재방문 쿨다운), 실패 무해(조용히 skip).
- **터치**: 신규 모듈(방명록 문구 프롬프트) + 신규 커맨드 + `api.ts` + 방문 훅. **diary 프롬프트 미접촉**.
- **세션**: **조건부 병렬** — 신규 파일 위주라 파일 충돌 적음. 단 "봇 성향" 문구 품질은 현재 세션 배관에 의존 → 배관 머지 후가 이상적.

### P4 — 누군가 내 방에 다녀가면 마스코트 말풍선 알림 *(+ 선택: 일기 반영)*
- 인바운드 방문 감지 → 마스코트 **말풍선**으로 "○○님 다녀갔어요"를 봇 톤으로 알림.
- **의존**: 인바운드 방문자 기록이 서버에 있어야 함. 현재 life-social 스펙엔 인바운드 방문 로그가 없음 → **a-hub 확장 필요**(방문 이벤트/최근 방문자 목록 API).
- **터치**: a-hub(방문 추적 API) **[별도 레포 · 완전 병렬]** + a-mate(폴링/이벤트 → 말풍선, `bubble.ts`).
- **선택**: 일기에도 "오늘 ○○ 놀러옴" 반영(P1 클러스터와 합류 가능).
- **세션**: a-hub 백엔드는 **완전 병렬**. a-mate 말풍선부는 서버 API 확정 후.

### P5 — 홈 화면 말풍선 텍스트 줄바꿈 개선 *(소품)*
- 증상: 사용자가 설정한 말풍선(`lifeSetBubble`)이 홈/방 화면에서 **단어 중간에서 깨지고** 어색하게 줄바꿈됨(예: "허락하/는"). 한국어 자동 줄바꿈이 어절 경계를 무시.
- 예상 수정: 말풍선 렌더러에 `word-break: keep-all`(어절 단위) + 사용자 입력 개행 존중(`white-space: pre-wrap`) + 적절한 max-width. 실제 원인·컴포넌트는 착수 시 확인.
- **터치**: 말풍선 렌더링(`bubble.ts` + 표시 컴포넌트 `RobotPortrait.svelte`/`MiniLife.svelte`/`Mascot.svelte` 중 해당). diary/프롬프트 미접촉.
- **세션**: 소규모·독립. 현재 세션과 파일 충돌 없음 → **완전 병렬(언제든 단독 처리 가능)**.

## 병렬 가능 요약

| 구분 | 아이템 |
|---|---|
| **완전 병렬(지금 가능)** | ⑩ a-hub 방문 추적 API(P4 백엔드, 별도 레포) · **P5 말풍선 줄바꿈(프론트 단독)** · 본 로드맵 각 아이템 상세 스펙 작성 |
| **조건부 병렬** | P3(신규 파일 위주 — 배관 머지 후 문구 품질 안정) |
| **순차(현재 세션 이후)** | P1 → P2 (`diary/mod.rs` 공유) |

## 착수 순서 제안

1. **(현재 세션)** 호칭·MBTI 문체 배관 머지.
2. **P3 + P4(a-hub API)** 병렬 착수 가능.
3. **P1 → P2** 순차.
