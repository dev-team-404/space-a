## 2. 구현 순서 (의존성 기준)

```
① 계약 정의        C1(MCP Tool) + C2(REST) 스키마 문서화
                   ↑ 팀 전체 공유. ★여기서부터 세 사람이 병렬 작업 가능★
                   │
② core + 인메모리   도메인 로직 + fake 어댑터로 E2E 통과
                   │
③ MCP 서버 붙이기   Claude Desktop/Cursor에서 실제 호출 성공
                   ↑ ★데모 최소 요건 — 여기까지만 되어도 발표는 성립★
                   │
④ 실 DB 교체       Vector 어댑터 구현
                   │
⑤ 클러스터 연결     llm_fake → llm_litellm 교체
                   │
⑥ 심야 압축 배치    유휴 GPU 활용 (킬러 피쳐)
                   │
⑦ 시각화 API 확정   Pillar 3에 실데이터 제공
```

### 컷라인의 의미

**③번까지만 되어도 데모는 성립한다.** ④~⑥은 완성도를 올리는 단계이므로,
시간이 부족하면 여기서 잘라도 **발표에 구멍이 나지 않는다.**

역으로 ①번이 늦어지면 **팀 전체가 늦어진다.** 계약이 없으면 아무도 병렬로 일할 수 없다.

## 3. 데모 시나리오

심사위원에게 보여줄 **"지식이 순환하는 순간"**.

| # | 단계 | 포인트 |
|---|---|---|
| 1 | **상황 발생** — 개발 에이전트가 코드 작성 중 처음 보는 라이브러리 의존성 에러에 직면 | 누구나 겪는 상황 |
| 2 | **로컬 작동** — 에이전트가 Space A(MCP)에 질의. 사내 로컬 LLM이 하이브리드 검색 수행 | **외부 API 비용 0** |
| 3 | **다회 검색** — 1차 검색이 부실하자 로컬 LLM이 에러 코드를 추출해 질의를 재구성, 2차에서 *"지난주 옆 팀 에이전트가 특정 MCP 환경변수를 수정해 해결했다"*는 사례를 적중 | **스스로 찾아내는 검색, 재시도 비용 0** |
| 4 | **최적화된 컨텍스트 전달** — 방대한 로그 대신 딱 필요한 "해결 조건 JSON"만 리턴 | **토큰 사용량 대폭 절감** |
| 5 | **최종 해결** — 에이전트가 최소 토큰으로 상용 모델을 호출해 코드 수정 성공 | |
| 6 | **지식 환류** — 해결 과정을 다시 Space A에 기록 → **다음 사람의 에이전트가 재사용** | **루프가 닫힌다** |

> 3~4번이 이 프로젝트의 기술적 클라이맥스다. 데모에서 **"이 JSON이 원본 로그였다면 N배였다"**를
> 나란히 보여주면 토큰 절감이 눈에 보인다.

## 5.5 자기 진화하는 공간 (신규 — 핵심 차별점)

**설계의 가장 큰 구멍이었다.** 01~05는 "에이전트가 지식을 어떻게 읽고 쓰나"만 다뤘고,
**공간이 어떻게 스스로 자라나**는 통째로 비어 있었다. 이게 Confluence와 갈라지는 지점이다.
→ [06-governance.md](06-governance.md)

> 상태: **설계 초안 — 팀 리뷰 전.** 아래 `[x]`는 "설계에 담겼다"는 뜻이지 "확정"이 아니다.
> 06 문서의 "초안 — 팀 리뷰 필요"와 같은 상태다.

- [x] 진화 층위 정의 (A 파라미터 / B 구조 / C 통제정책은 사람 몫으로 제외)
- [x] 통제 모델 — 변경 등급 L0~L3, 매핑은 사람이 정하는 진화 정책
- [x] 매니저 에이전트 성격 (하이브리드: 처방=규칙, 판단=LLM)
- [x] Space 생애주기 (active → dormant → archived, **지식은 안 지움**)
- [x] 멤버십 원천 (`spaces[]`가 어디서 오는가) + 오너 승계
- [x] 토큰 예산 — **차단이 아니라 단계적 저하.** 기록은 최후까지 받음
- [x] 지식 신뢰도 — **사람 승인이 아니라 재사용 성패가 검증**
- [ ] C1/C2에 추가 필요 (`/manager-events`, `/evolution`, `trust`, `flag_knowledge`) — **파괴적 변경 아님**
- [ ] **팀 리뷰** — 특히 "울타리의 초기 위치"(무엇을 auto/approval로)
