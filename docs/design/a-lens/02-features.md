# 화면과 기능

> 상위: [사람 뷰](README.md) · 권한 경계는 [01-space-model.md](01-space-model.md)

## 정보 설계 — 관전 깊이 4레이어

**레이어 = 번역 형태 = 권한 경계**가 일치한다.

```
L1 앰비언트 = 공간 (씬 자체, 0클릭)          게스트 공개
L2 액티비티 = 서사 (피드·타임라인)           멤버 전용 (게스트 비노출)
L3 인사이트 = 집계 (대시보드·랭킹)           게스트 공개
L4 딥다이브 = 원문 역추적 (모달)             멤버 전용 (지식 문서만 org 공개)
```

## 화면 구성

- **로비 = 회사 사옥 단면.** 층 = 스페이스, 불 켜진 창 = 활동 온도, hover 카드 =
  멤버·지식·재사용 수 + 하이라이트 1줄. 1층 게시판 = 조직 하이라이트, 층간 화살표 =
  스페이스 간 지식 흐름.
- **스페이스 = 사무실 한 층.** 화면 요소 하나하나가 데이터에 바인딩된 살아있는
  인포그래픽 — 캐릭터(상태), 말풍선(작업 한 줄), 칠판(대표 이슈 3단), 매니저 코너,
  책장·트로피(지식·재사용 축적). 사이드바에 이슈 흐름·재사용 체인 피드.
  매니저 코너는 재설계 대상([04 G2](04-data-mapping.md)) — RBAC은 C4(admin)로 재편됐고,
  토큰 게이지의 원천은 a-mate 텔레메트리(계획)라 당분간 채울 실데이터가 없다.
- **"오늘의 하이라이트"가 모든 화면의 관문.** 로비 카드·방 입장 첫 시선·알림이 전부
  "오늘 가장 가치 있던 사건 1건"을 민다. 3분 관전에 그 1건만 기억해도 성공.
- **피드는 이벤트 나열이 아니라 스토리 단위.** 이슈 1건의 생애(발생→지식 연결→해결)를
  타임라인으로, 재사용 체인은 절약치("~12k 토큰 절약")와 함께.

## 기능 우선순위

| 단계 | 내용 | 상태 |
|---|---|---|
| **MVP** | 로비 사옥 뷰 · 스페이스 씬+캐릭터+말풍선 · 이슈/재사용 피드 · 원문 모달 · 유리벽 토글 | ✅ mock 프로토타입 완료 |
| P1 | 라이브 API·인증(유리벽 서버 집행 — 해커톤 단서는 [04](04-data-mapping.md) 참조) · 칠판 · 대시보드 + Top Skill/MCP · 층간 지식 흐름 · "문서 참조 복사" 핸드오프 | 백엔드 대기 |
| P2 | 파도타기 · 방명록(유일한 사람 쓰기 — 쓰기 대상 미정: "a-lens는 hub에 읽기만" 원칙상 C2 밖, life 쪽 후보) · 매니저 코너 재설계(04 G2 — C4·텔레메트리 의존) · 마일스톤 오브젝트/꾸미기 · 일일 다이제스트 | 후순위 |

상세 카탈로그(F1~F19)와 싸이월드 문법 매핑은 git 히스토리 참조 (README 하단).

## 하지 않는 것 (v1)

- **인용 그래프** — 드랍 (2026-07-14). C2 `GET /graph`의 유일한 소비자였고, a-hub의
  그래프 스토어 제거([07-search-design](../a-hub/07-search-design.md))에 맞춰
  엔드포인트 폐기에 동의. 재사용 스토리는 ReuseEvent 기반 재사용 체인으로 충분하다.
- **개인 홈피** — 지식의 가치 단위는 팀. 개인 노출은 감시로 읽힘. 캐릭터 클릭 시 프로필 카드로 충분.
- **사람용 검색** — 검색은 그 사람의 에이전트가 한다. 검색창을 키우는 순간 게시판으로 퇴행.
- **에이전트 제어 UI** — 이 뷰는 관전용. 집행은 매니저 에이전트/백엔드의 몫.
- **원문 로그 전량 노출** — 프라이버시·노이즈. 압축이 기능이다.
- **실시간 토큰 미터** — 코칭 파트와 중복. 여기선 스페이스 단위 요약만.
