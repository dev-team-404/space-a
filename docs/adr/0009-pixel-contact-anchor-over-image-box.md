# ADR 0009: 이미지 박스가 아닌 픽셀 접지점을 배치 기준으로 사용한다

- 상태: 채택
- 날짜: 2026-07-18
- 대체 범위: ADR 0008의 책상 이미지 박스 X 비율 강제 규칙과 원형 테이블 접지점

## 배경

ADR 0008은 책상 PNG 박스 전체 폭을 회전된 footprint의 투영 폭에 맞추고, 이미지 X 앵커를
`x_span / (x_span + y_span)`으로 강제했다. 이 값은 footprint 전면 꼭짓점의 화면상 비율이지만,
PNG의 투명 박스 좌우 끝은 바닥 꼭짓점이 아니라 상판, 거울, 수납장처럼 높이가 있는 실루엣의
끝일 수 있다. 따라서 이미지 박스 비율을 접지점으로 사용하면 실제 최하단 다리나 수납장 받침이
전면 꼭짓점에서 옆으로 밀린다.

책상 원본 두 방향의 최하단 접지 X를 비교하면 이 오류가 방향별로 그대로 재현된다. 회전
`↗/↖`이 사용하는 `sw` 원본에서는 2·3·4번 책상의 차이가 크고, `↘/↙`이 사용하는 `ne`
원본에서는 다섯 책상 모두 강제 비율과 차이가 난다. 이는 별도 회전 예외가 아니라 측정한
접지점을 버린 한 가지 규칙의 문제다.

원형 테이블의 최하단 픽셀은 받침의 전면 끝이다. 이 픽셀을 2×2 footprint 중앙
`[0.5,0.5]`에 놓으면 받침 전체가 뒤쪽으로 치우치고, 전면 꼭짓점 `[1,1]`에 놓으면 받침이
셀 밖으로 내려간다.

## 결정

- PNG의 `ground=[x,y]`는 투명 픽셀을 제외한 최하단 접촉 구간의 중앙점이다.
- 바닥 가구의 이미지 앵커는 자산·원본 방향별 `ground`를 사용한다. 좌우 반전한 뷰는
  `x'=1-x`를 사용한다.
- footprint의 투영 폭은 렌더 크기와 충돌 셀을 결정하지만, 이미지 박스 좌우 끝을 footprint
  꼭짓점으로 간주하지 않는다.
- 책상의 base size와 회전 축은 ADR 0008의 `[3,2]`·`[4,2]` 규칙을 유지한다. 변경되는 것은
  이미지 X 앵커뿐이다.
- 2×2 원형 테이블의 받침은 중앙 1×1 영역에 있다고 본다. 최하단 픽셀은 그 받침의 전면
  끝이므로 footprint 접지점은 `[0.75,0.75]`다.
- 벽 가구의 전단 보정은 ADR 0008을 유지하며, 전단 후 접지 Y에도 같은 행렬을 적용한다.

## 검증

- 책상 5종의 네 회전 이미지 X 앵커가 선택된 원본의 측정 접지 X 또는 그 반전값과 일치한다.
- 회전별 footprint 크기는 ADR 0008과 동일하게 유지된다.
- 원형 테이블의 접지점은 `[0.75,0.75]`이며 2×2 전면 꼭짓점보다 위, 중앙보다 아래에 놓인다.
- 로컬 편집 화면에서 책상 5종을 네 방향으로 배치해 최하단 다리·수납장과 점유 셀을 비교한다.
