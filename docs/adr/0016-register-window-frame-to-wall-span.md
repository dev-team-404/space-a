# ADR 0016: 창문 프레임을 실제 벽 점유 구간에 등록한다

- 상태: 채택
- 날짜: 2026-07-20
- 대체 범위: ADR 0008의 창문 기울기 보정은 유지하고 크기·앵커 계약을 구체화한다

## 배경

창문 배치 셀은 벽의 아이소메트릭 축을 따라 연속된 구간이지만 렌더 폭은
`max(62, span × tileWidth × 0.78)`이라는 별도 경험값을 사용했다. 또한 이미지의 가장 낮은
불투명 픽셀을 벽 구간 중앙에 붙여, 원본에 따라 프레임의 왼쪽 또는 오른쪽 끝이 배치 중심이
되었다. 그 결과 3셀 창문은 점유 구간보다 약 2.3배, 5셀 창문은 약 1.6배 넓게 보이고 위치도
품목별로 달랐다.

## 결정

- 벽 한 셀의 화면 X축 폭은 바닥 투영과 동일하게 `tileWidth / 2`로 계산한다.
- 창문 렌더 폭은 `span × tileWidth / 2`로 하며 최소 폭을 강제하지 않는다.
- 창문 앵커 X는 프레임 하단선의 중앙인 `0.5`로 통일한다.
- 하단선 앵커 Y는 측정된 최저점과 원본 하단선 기울기로 중앙점을 복원한 뒤, 화면에 적용하는
  좌우 반전·전단과 동일한 변환을 적용해 계산한다.
- 벽 위의 수직 배치 높이는 기존 디자인 기준인 바닥에서 벽 높이의 30% 지점을 유지한다.

## 결과

- 3셀과 5셀 창문 모두 선택한 벽 셀 구간의 시작·끝에 렌더 프레임이 맞는다.
- 원본의 최저점이 어느 쪽 모서리에 있든 프레임 중앙이 점유 구간 중앙에 놓인다.
- 창문 기울기, 렌더 폭, 앵커가 하나의 아이소메트릭 좌표 계약을 공유한다.

## 검증

- 3셀·5셀 벽 구간의 화면 폭을 단위 테스트한다.
- 모든 창문 방향에서 앵커 X가 `0.5`이고 하단선 중앙 Y가 화면 변환과 일치하는지 검사한다.
- 편집 화면에서 점유 셀 오버레이와 실제 창틀의 양 끝을 비교한다.
