# ADR 0007: footprint 축과 월드 접지 앵커 분리

- 상태: 채택
- 날짜: 2026-07-18
- 대체 범위: ADR 0004·0005의 모든 자산을 화면 전면 꼭짓점에 고정하는 규칙

## 배경

이미지의 실제 방향을 맞춰도 논리 footprint의 기본 장축이 이미지와 직각이면 책상 본체나
수납장이 점유 셀 밖으로 보인다. 또한 PNG 최하단 접점이 중앙 받침대인 원형 테이블을 모든
가구의 기본 화면 전면 꼭짓점에 결합하면 받침대가 footprint 아래쪽 경계를 벗어난다.

이미지 내부 접점과 월드 footprint 내부에서 그 접점이 놓일 위치는 서로 다른 데이터다.

## 결정

- 기본 `size`는 회전 0도의 이미지 축과 일치해야 한다. 책상 5종은 각각 `2×3`, `2×4`,
  `2×3`, `2×3`, `2×4`로 정의한다.
- 책상 본체와 수납장은 모두 충돌 대상이므로 책상 footprint는 바운딩 박스 전체를 점유한다.
- 카탈로그는 이미지 내부의 `ground_anchor`와 별도로 정규화된 월드
  `footprint_anchor=[x,y]`를 가진다.
- `footprint_anchor=[1,1]`은 회전된 바운딩 박스의 화면 전면 꼭짓점이며 기존 가구의 기본값이다.
- 중앙 받침대형 원형 테이블은 `[0.5,0.5]`를 사용해 받침대 접점을 2×2 footprint 중심에 둔다.
- 저장된 알려진 `asset_id`를 읽을 때 클라이언트 카탈로그의 최신 `category`, `size`,
  `footprint`로 정규화한다. 따라서 과거 축·마스크 값은 다음 저장 시 최신 계약으로 이관된다.

창문의 회전은 벽에서 파생되는 의미 방향이고, PNG 좌우 반전은 해당 벽 평면에 맞추는 렌더
선택이다. 창문 PNG마다 원본 상단 모서리 기울기(`up-right` 또는 `down-right`)를 기록하고,
목표 벽 평면의 기울기와 다를 때만 좌우 반전한다. 두 값을 동일한 조건식으로 취급하지 않는다.

## 검증

- 책상 5종의 기본 크기와 모든 footprint 셀을 단위 테스트로 고정한다.
- 원형 테이블의 이미지 접점은 2×2 footprint 중심에 투영된다.
- 창문 5종 모두 좌상벽(`west=90`)에서는 `up-right`, 우상벽(`north=180`)에서는
  `down-right` 기울기가 되며, 원본 기울기가 서로 다른 창문도 같은 벽면 원근을 유지한다.
- 기존 저장 객체가 카탈로그 크기·footprint로 정규화되는 동작을 테스트한다.
