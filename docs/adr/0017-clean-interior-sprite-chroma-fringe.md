# ADR 0017: 인테리어 스프라이트의 크로마 경계를 결정적으로 정리한다

- 상태: 채택
- 날짜: 2026-07-20
- 대상: `a-mate/src/assets/interior/furniture/**/*.png` 생성·정리 과정

## 배경

인테리어 원본 시트는 마젠타 배경을 임계값으로 제거해 투명 PNG로 분리했다. 기존 분리기는
배경색과 전경이 섞인 안티앨리어싱 픽셀을 전경으로 분류한 뒤 알파를 255로 고정한다. 그 결과
전체 에셋 경계 픽셀 중 약 54%가 마젠타 우세 색상으로 남아 밝은 바닥과 벽에서 보라색 외곽선처럼
보인다.

전체 이미지의 보라색을 색상 키로 제거하면 파스텔 가구의 정상적인 보라·분홍 재질까지 손상된다.
생성형 이미지 편집은 원본 픽셀과 형상을 보존하지 못하므로 배포 에셋 정리에는 사용할 수 없다.

## 결정

- 투명 픽셀에서 2px 이내인 불투명 경계만 크로마 오염 후보로 본다.
- 후보 중 `min(red, blue) - green >= 25`인 마젠타 우세 픽셀만 보정한다.
- 내부 전경은 수정하지 않는다.
- 보정색은 가장 가까운 비마젠타 내부 픽셀의 색조를 사용하되 원래 픽셀의 밝기를 유지한다.
- 적절한 내부 표본이 없으면 같은 밝기의 중립적인 보라 회색을 사용한다.
- 알파와 캔버스 크기, 불투명 픽셀 수, 파일 경로는 유지한다.
- 분리 스크립트로 새 에셋을 만든 뒤 동일한 정리 단계를 실행해 재발을 막는다.

## 검증

- 모든 출력 PNG의 크기와 알파 점유 마스크가 입력과 동일해야 한다.
- 내부 픽셀은 바이트 단위로 동일해야 한다.
- 경계 마젠타 픽셀 수를 처리 전후로 집계한다.
- 메탈 워크스테이션, 소파, 가전, 파스텔 화장대, 창문을 포함한 비교 시트를 확인한다.
