# ADR 0010: 책상 원본 투영축을 방 격자에 등록한다

- 상태: 채택
- 날짜: 2026-07-18
- 대체 범위: ADR 0009의 책상 이미지 X 앵커 규칙

## 배경

ADR 0009는 모든 바닥 가구의 최하단 불투명 픽셀 구간을 footprint 전면 접점으로 사용했다.
그러나 책상의 최하단 픽셀은 방향과 원본에 따라 서로 다른 다리에서 나온다. 이 접점을 전체
직사각 footprint의 전면 꼭짓점에 고정하면 같은 책상이 회전할 때 이미지 박스 전체가 좌우로
이동한다. 특히 `↘`과 `↙`이 공유하는 `ne` 원본에서는 잘못된 이동 때문에 원본 상판 축과 점유
마름모의 차이가 더 크게 보였다.

일부 `ne` 원본은 상판의 두 평행 모서리도 완전히 평행하지 않다. 접점 평행이동만으로는 이
원근 오차를 고칠 수 없고, 방향별 수동 오프셋을 추가하면 좌우 반전 뷰가 다시 갈라진다.

## 결정

- 책상은 카탈로그의 전체 직사각 `size`를 시각 등록 경계로 사용한다.
- 책상 이미지 X 앵커는 회전된 footprint 전면 꼭짓점의 투영 비율
  `projectedWidth / (projectedWidth + projectedHeight)`로 계산한다. 최하단 다리 X는 사용하지 않는다.
- 각 `ne` 책상 원본에서 상판의 양쪽 외곽선을 측정하고, 같은 축에 해당하는 두 선의 기울기를
  평균내 `positiveSlope`, `negativeSlope`로 기록한다.
- 방 바닥축의 목표 기울기는 각각 `+0.5`, `-0.5`다. 원본 Y 좌표에 다음 행렬을 적용한다.

  ```text
  scaleY = 1 / (positiveSlope - negativeSlope)
  shearY = 0.5 - scaleY * positiveSlope
  y' = scaleY * y + shearY * x
  ```

- `↙`처럼 원본을 좌우 반전하는 뷰는 같은 `scaleY`와 반대 부호의 `shearY`를 사용한다.
- 이미지 박스 앵커 Y에도 렌더 이미지와 동일한 행렬을 적용한다. 화면 변환과 배치 변환을 따로
  보정하지 않는다.
- 행렬 적용 후 원본의 최하단 불투명 실루엣과 footprint의 두 전면 경계를 비교한다. 경계를 넘는
  최대 Y 거리를 이미지 높이로 정규화한 `boxLift`를 기록하고 앵커 Y에 더한다. 이 값은 방향별
  수동 오프셋이 아니라 같은 원본 박스를 점유 경계 안에 포함하기 위한 원본별 값이며, 좌우 반전
  뷰에서 그대로 재사용한다.
- `sw` 원본을 사용하는 `↗`·`↖`은 현재 방 축 허용 오차 안에 있으므로 이번 결정에서 변형하지
  않는다.

## 결과

- `↘`과 `↙`은 하나의 원본 축 메타데이터에서 파생되어 서로 반대 방향으로 같은 정도만 보정된다.
- 책상 위치가 어느 다리가 우연히 가장 낮은지에 따라 바뀌지 않는다.
- 원본 자체에서 두 대응선이 완전히 평행하지 않은 잔여 왜곡은 평균축 기준으로 최소화한다.
- 향후 원본을 교체할 때 임의 오프셋 대신 두 축 측정값만 갱신하면 된다.

## 검증

- 다섯 책상 모두 `↘`에서 변환된 두 원본 축이 `+0.5/-0.5`인지 검사한다.
- 같은 다섯 책상의 `↙` 좌우 반전에서도 두 축이 `+0.5/-0.5`인지 검사한다.
- 네 회전의 이미지 X 앵커가 회전된 footprint 전면 꼭짓점 비율과 일치하는지 검사한다.
- `↘`·`↙` 합성 화면에서 최하단 실루엣이 footprint 전면 경계를 넘지 않는지 검사한다.
- 편집 화면에서 다섯 책상을 `↘`·`↙`으로 나란히 배치하고 점유 셀 외곽선과 상판 축을 확대 비교한다.
