# ADR 0011: 책상은 원본별 다중 지지점과 격자 정합 에셋으로 배치한다

- 상태: 채택
- 날짜: 2026-07-18
- 대체 범위: ADR 0007·0008의 2·5번 책상 크기, ADR 0010의 책상 이미지 박스 앵커와 `boxLift`

## 배경

책상 PNG 전체 박스나 최하단 픽셀 하나를 기준으로 배치하면 다음 문제가 반복된다.

- 한쪽 다리를 맞추면 반대쪽 다리가 점유 셀을 벗어난다.
- 같은 원본을 좌우 반전한 방향마다 별도 오프셋이 필요해진다.
- 원본의 바닥 투영 비율이 3×2 격자와 다르면 평행 이동과 균일 확대만으로 네 접점을 동시에 맞출 수 없다.
- 이미지 전체에 전단이나 비균일 변형을 적용하면 다리와 거울 기둥이 기울어진다.

따라서 배치 기준은 이미지 박스가 아니라 바닥에 닿는 지지점 집합이어야 하며, 원본 원근 자체가 잘못된 에셋은 렌더 보정이 아니라 에셋 기하를 교체해야 한다.

## 결정

- 다섯 책상의 base size와 footprint는 모두 `[3,2]`, 6셀로 통일한다. 회전 시 점유 크기는 `[2,3]`이 된다.
- `sw`, `ne` 원본마다 보이는 다리·패널 하단의 지지점 좌표를 픽셀 단위로 등록한다. 좌우 반전 방향은 같은 좌표의 X축 반전을 재사용한다.
- 일반 책상은 모든 지지점이 점유 셀 안에 들어오는 최대 균일 배율과 평행 이동만 계산한다. 방향별 수동 오프셋, `boxLift`, 이미지 전체 전단은 사용하지 않는다.
- 원본의 바닥 투영 비율이 3×2와 다른 에셋은 이 계산으로 억지로 전단하지 않는다. 네 모서리의 완전 정합이 필요하면 별도 에셋 교체 ADR에서 2:1 격자에 맞는 독립 원본으로 교체한다.
- 화면의 2:1 아이소메트릭 좌표로 바꿀 때 접점 `(x, y)`는 다음 축으로 변환한다.

  ```text
  u = (x + 2y) / 2
  v = (2y - x) / 2
  ```

- 회전 footprint가 `w × h`이면 허용 범위는 `-w + padding <= u <= -padding`, `-h + padding <= v <= -padding`이다. 기본 `padding`은 `0.02`칸이다.
- 서버에 저장하는 `size`, `footprint`, `rotation` 계약은 바꾸지 않는다. 지지점과 렌더 값은 같은 클라이언트 카탈로그 버전에 포함한다.

## 결과

- 모든 지지점이 3×2 셀 안에 들어가고, 네 방향은 두 원본과 좌우 반전으로만 파생되어 방향별 땜질 오프셋이 사라진다.
- 원본 기하가 격자 비율과 다른 경우 네 모서리의 완전 정합까지 보장하지는 않는다. 이 한계를 렌더 오프셋으로 숨기지 않고 에셋 교체 대상으로 분리한다.

## 검증

- 다섯 책상 × 네 방향에서 등록 지지점이 회전 footprint 안에 들어가는지 검사한다.
- 같은 책상의 네 방향 렌더 너비와 좌우 반전 앵커가 대칭인지 검사한다.
- 편집 화면에서 점유 셀 오버레이와 네 접점을 함께 표시해 컴퓨터 책상, 메탈 워크스테이션, 파스텔 화장대를 네 방향 모두 시각 확인한다.
