# ADR 0005: 독립 가구 자산과 접지 메트릭

- 상태: 채택
- 날짜: 2026-07-18
- 대체 범위: ADR 0004의 식탁 세트 자산, 방향별 원본 선택, 공통 하단 중앙 앵커 규칙

## 배경

한 이미지에 테이블과 의자를 함께 넣은 `dining` 자산은 방향별 생성 결과에서 의자 수와 배치가
달라졌다. 서로 독립 생성된 네 방향 PNG는 같은 `asset_id`여도 구성·카메라·비율이 달랐으며,
모든 PNG를 `[0.5, 1]`로 접지하면 실제 다리나 받침의 바닥 접점과 점유 셀 기준점이 어긋났다.

렌더 폭도 자산별 감각값으로 지정되어 같은 점유 셀을 쓰는 조명이 서로 다른 배율로 보였다.
이 문제들은 개별 CSS 오프셋으로 보정하지 않고 자산 생성·메타데이터 계약에서 해결한다.

## 결정

### 테이블과 의자 분리

- `dining` 카테고리와 `dining.*` 자산은 제거한다.
- 새 카테고리는 `table`과 `chair`이며 각각 독립 배치·회전·삭제할 수 있다.
- 테이블 footprint에는 테이블 본체가 실제로 차지하는 셀만 포함한다.
- 의자는 종류와 관계없이 독립 1×1 footprint를 가진다.
- 기존 room-server 저장소의 `category='dining'` 객체는 시작 시 삭제한다. 호환 변환은 제공하지 않는다.

### 동일 개체의 2면 원본

- 각 바닥 자산은 같은 개체를 같은 카메라와 배율로 그린 `NE`와 `SW` 두 원본만 가진다.
- `0=NE`, `90=mirror(NE)`, `180=SW`, `270=mirror(SW)`로 4방향을 파생한다.
- 소파·책상·테이블처럼 방향성이 있는 자산도 이 규칙을 예외 없이 사용한다.
- 창문은 한 벽면 원본만 가지며 다른 벽면은 정확한 좌우 반전으로 만든다.
- 최종 저장소에는 자산별 독립 PNG만 둔다. 생성용 시트는 저장소와 런타임에서 사용하지 않는다.

### 픽셀 접지 메트릭

각 채택 PNG는 투명 배경으로 정리한 뒤 다음 메트릭을 가진다.

```text
pixel_width
pixel_height
ground_anchor_x
ground_anchor_y
```

- `ground_anchor`는 이미지 바운딩 박스 중심이 아니라 실제 바닥에 닿는 최하단 픽셀 군집에서 계산한다.
- 좌우 반전한 방향의 X 앵커는 `1 - source_anchor_x`이다.
- 렌더러는 `ground_anchor`를 회전된 footprint의 화면 전면 꼭짓점
  `cell + rotatedSize`에 결합한다.
- 점유 셀과 이미지 접지는 공통 함수만 사용하며 자산별 CSS `left/top` 보정값을 두지 않는다.
- 편집 모드에서는 배치된 객체의 점유 셀과 접지점을 오버레이해 이 계약을 직접 확인할 수 있어야 한다.

### 셀 기준 배율

- 렌더 폭은 픽셀 원본 크기가 아니라 footprint 투영 폭에서 계산한다.
- 1×1 조명과 의자는 같은 기준 폭 범위에 둔다. 세로 높이는 원본 비율대로 유지한다.
- 아크 조명처럼 실제 footprint가 큰 경우에만 더 큰 폭을 사용한다.
- 카탈로그 썸네일은 방 렌더 배율과 분리하고 `contain`으로 전체 자산을 표시한다.

## 검증

- 테이블 5종과 의자 5종은 서로 다른 카테고리에 표시되고 독립 배치된다.
- 저장소와 카탈로그에 `dining.*` 신규 자산이 없고 기존 저장 객체도 제거된다.
- 모든 바닥 자산은 0/90에서 동일 PNG, 180/270에서 동일 PNG를 사용하며 각 쌍의 반전값만 다르다.
- 방향을 바꿔도 책상 구성, 가전 버튼·문·스피커 수, 소파 쿠션 수가 달라지지 않는다.
- 각 방향에서 이미지의 실제 바닥 접점과 점유 셀 전면 꼭짓점이 같은 화면 좌표다.
- 1×1 조명은 서로 비슷한 바닥 폭으로 렌더되고, 큰 조명만 footprint에 비례해 커진다.
- 창문은 설치 벽과 평행한 두 방향 외에는 배치·회전할 수 없다.
