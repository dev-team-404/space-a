# ADR 0015: 바닥 가구 스프라이트의 투영 축을 선택적으로 정규화한다

- 상태: 채택
- 날짜: 2026-07-20
- 대체 범위: ADR 0011의 "원본 교체 전에는 책상 전체 투영을 보정하지 않는다" 제한

## 배경

바닥 격자는 기울기 `+0.5`, `-0.5`인 2:1 아이소메트릭 평면이지만 가구 PNG는
품목과 원본 방향마다 서로 다른 카메라 기울기를 가진다. 접점과 footprint만 맞추면 충돌
영역은 올바르지만, 같은 가구를 옆 셀에 이어 놓았을 때 상판과 프레임이 격자선에 평행하지
않아 배치가 흔들려 보인다.

모든 PNG에 같은 전단을 적용할 수도 없다. 원형 테이블, 조명, 의자처럼 두 투영 축을
신뢰성 있게 측정할 직선 면이 없는 품목은 강제 변환이 형태만 왜곡한다.

## 결정

- 소파, 책상, 사각 테이블, 직육면체 가전처럼 두 개의 직선 투영 축을 식별할 수 있는
  원본에는 `positiveSlope`, `negativeSlope`를 원본 방향별로 등록한다.
- 등록한 두 축은 다음 affine Y 변환으로 바닥 격자의 `+0.5`, `-0.5`에 맞춘다.

  ```text
  scaleY = 1 / (positiveSlope - negativeSlope)
  shearY = 0.5 - scaleY * positiveSlope
  y' = scaleY * y + shearY * x
  ```

- 좌우 반전 뷰는 원본 축의 부호와 순서를 함께 반전한 뒤 같은 식으로 변환한다.
- 원형·유기적 품목과 축 측정 신뢰도가 낮은 품목은 `scaleY=1`, `shearY=0`을 유지하고
  기존 바닥 접점 앵커만 사용한다.
- 앵커와 책상 지지점 등록 계산에도 화면과 동일한 affine 변환을 적용한다. 화면 변환과
  배치 변환에 서로 다른 보정값을 사용하지 않는다.
- 변환은 원본별 메타데이터로 관리하며 방향별 임의 위치 오프셋은 추가하지 않는다.

## 결과

- 직선 모서리가 있는 가구를 연속 배치하면 모서리가 셀의 두 축과 평행해진다.
- 책상 지지점과 모든 가구의 바닥 앵커는 변환 후에도 기존 footprint에 등록된다.
- 축을 판별할 수 없는 품목은 불필요한 찌그러짐 없이 기존 형태를 유지한다.

## 검증

- 등록된 모든 원본 축이 변환 후 `+0.5`, `-0.5`인지 단위 테스트한다.
- 모든 projection의 수직 배율과 전단이 허용 범위 안인지 검사한다.
- 편집 화면에서 동일 품목을 X축·Y축으로 연속 배치해 격자선과 모서리를 비교한다.
