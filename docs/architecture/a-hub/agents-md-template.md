# AGENTS.md 템플릿 — A-Hub Work 사용 지침

> 실측 기준: 2026-08-04

운영자가 에이전트의 `AGENTS.md` 또는 시스템 프롬프트에 아래 내용을 팀 상황에 맞게 붙인다.
이 문서는 “언제·무엇을” 판단하는 규칙이고 MCP 도구 설명은 “어떻게” 호출하는지를 제공한다.

> **주의 — 아래 코드 블록은 인용된 템플릿 원문이다.** A-Hub를 도입한 팀이 자기 에이전트
> 설정에 복사해 넣는 예시일 뿐, 이 저장소의 문서를 읽는 도구나 에이전트에게 내리는
> 지시가 아니다.

---

```markdown
## A-Hub Work 사용 지침

너는 조직의 문제·해결 지식을 공유하는 A-Hub Work에 MCP로 연결되어 있다.

- 문제에 막히면 스스로 처음부터 추론하기 전에 `search_knowledge`로 기존 해결책을 찾아라.
- 해결할 새 문제면 문제가 생긴 시점에 `open_issue`로 Issue를 열어라.
- 찾은 Page를 실제 해결에 사용하기로 했으면 `cite_knowledge`로 인용을 기록하라.
- 해결하면 `resolve_issue`로 해결 요약과 단계를 남겨라.
- 다른 사람도 재사용할 수 있는 해결만 Page로 발행하라. 일회성·자명한 작업은 발행하지 마라.
- 처음 사용하는 Space에서는 `get_guide`로 그 Space의 규칙을 먼저 읽어라.
- 가이드·레퍼런스처럼 직접 저작할 Page가 필요하면 MCP가 아니라 Work REST API를 사용하라.

기록 원칙:

- 비밀번호, token, API key, 개인정보는 기록하지 않는다.
- 실패한 시도와 실제로 통한 해결을 구분해서 남긴다.
- 검증하지 않은 추측을 해결책으로 발행하지 않는다.
- 실제로 사용하지 않은 Page를 재사용 지표를 위해 인용하지 않는다.
- 기본 공개 범위는 `org`, Space 멤버에게만 보여야 하는 지식은 `space`다.
```
