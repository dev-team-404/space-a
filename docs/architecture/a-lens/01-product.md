# A-Lens — 제품 범위와 원칙

> 실측 기준: 2026-08-04

## 1. 한 줄 정의

**A-Lens는 에이전트가 남긴 업무 기록과 현재 사람 상태를, 팀이 관전할 수 있는 2D 공간과 사람용 이야기로 번역하는 웹 서비스다.**

## 2. 해결하는 문제

| 문제 | A-Lens의 답 |
|---|---|
| A-Hub의 Issue·Page·ReuseEvent는 사람이 훑기에는 구조적이고 양이 많다 | 팀·사람·시간 축으로 묶고 짧은 요약과 서사로 바꾼다 |
| 누가 무엇을 했는지 API 응답만으로는 관계가 보이지 않는다 | 사람, 문서, 이슈 사이 관계를 방과 협업 지도로 표현한다 |
| 업무 데이터만 보면 팀의 현재 온도가 느껴지지 않는다 | Life의 이름·마스코트·프레즌스를 Work 활동과 결합한다 |
| 원천 서버나 LLM이 잠시 실패하면 관전 화면 전체가 비기 쉽다 | 마지막 스냅숏, 데모 데이터와 규칙 기반 폴백으로 화면을 유지한다 |

## 3. 사용자와 사용 방식

주 사용자는 팀원과 팀 리더다. 둘 다 원문을 검색하거나 업무를 집행하기보다, 짧게 들어와 현재 흐름과
재사용된 지식을 확인한다. 검색·Issue 처리·Page 발행은 A-Hub와 에이전트의 책임으로 남긴다.

현재 UI가 제공하는 쓰기는 A-Hub 업무 데이터에 대한 쓰기가 아니다. 사용자가 고른 방 배경·책상·책상 수는
A-Lens의 `rooms.json`에, Work·Life·LLM 연결 설정은 `settings.json`에 저장한다.

## 4. 제품 원칙

### 4.1 원천이 아니라 번역 계층

A-Lens는 Issue, Page, 사용자 신원의 정본이 아니다. Work와 Life API를 읽고 화면용 파생 상태를 만든다.
원천이 바뀌면 다음 수집에서 다시 계산할 수 있어야 한다.

### 4.2 수치는 결정론, 문장은 제한된 생성

문서 수, 해결 수, 재사용 수, 상태와 관계 엣지는 원천 데이터와 규칙으로 계산한다. LLM은 폐쇄된 카테고리
분류, 표시용 제목, 요약과 한 줄 서사에만 사용한다. LLM이 실패해도 원문 일부와 규칙 문장으로 화면이 유지된다.

### 4.3 사람과 팀이 주인공

화면은 에이전트 계정 ID보다 Life의 사람 이름과 마스코트를 우선한다. 한 사람에게 여러 Work 계정이
연결되면 가능한 범위에서 한 사람으로 합친다. 개인 생산성 순위를 만들지 않고, 팀 안의 기록과 협업 관계를 보여준다.

### 4.4 압축과 역추적

첫 화면에는 상태와 하이라이트를 압축해 보여주고, 상세 패널과 모달에서 Issue 타임라인과 Page 원문으로
내려갈 수 있게 한다. 요약만 남기고 근거를 잃거나, 원문 전체를 첫 화면에 나열하는 두 극단을 피한다.

### 4.5 실패 격리

Work, Life, LLM과 협업 지도 중 하나가 실패해도 가능한 나머지 화면은 계속 열린다. Life 연결이 없으면
Work-only 사람 정보로, LLM이 없으면 규칙 번역으로, 협업 지도 계산이 실패하면 빈 지도로 강등한다.

## 5. 현재 범위

- Space별 관전 방 생성·수정·삭제와 서버 공유 저장
- PixiJS 기반 방·캐릭터·칠판·책장 렌더링
- 사람별 작업 기록, Issue 흐름, 재사용 이벤트와 Page 원문
- 사람 간 협업 지도와 프로젝트별 부분 지도
- 오늘의 하이라이트 선정과 방 관점의 결정론 문장화
- Work 수집, Life 신원·프레즌스·마스코트 결합
- Page·Issue의 표시 제목·분류·요약과 서사 번역
- 런타임 연결 설정, 연결 테스트와 캐시 무효화
- 더미·계약 픽스처를 이용한 데모와 실패 폴백

## 6. 비목표

- A-Hub의 Issue·Page를 만들거나 수정하는 관리 UI
- 사람용 전문 검색 제품
- 개인별 생산성·토큰 사용량 순위
- A-Hub 인증·권한을 대신하는 접근 제어 계층
- Work 또는 Life의 정본 DB
- 여러 사용자가 동시에 편집하는 범용 인테리어 플랫폼

초기 설계에 있던 사옥 단면 로비, 유리벽 기반 게스트 권한 연출, 팀 대시보드와 파도타기는 현재 코드에
구현된 기능으로 문서화하지 않는다. 남아 있는 구상은 [`docs/archive/design/a-lens/`](../../archive/design/a-lens/)에서만 다룬다.
